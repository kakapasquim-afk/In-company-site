## Aprendizados

- O site estático usa **HTML5 semântico** + **CSS puro** com tokens em variáveis `oklch` + **JavaScript vanilla** (sem frameworks e sem build para a home).
- As **páginas de projeto** (`projetos/*.html`) são montadas por um script PowerShell (`projetos/build.ps1`) que combina `_head.html` + `_header.html` + `_body-*.html` + `_footer.html`, substituindo `__TITLE__` e `__DESC__`.
- As fontes são carregadas via Google Fonts: **Manrope** (títulos) e **Inter** (corpo).
- Os tokens visuais vivem em `css/styles.css`; o vermelho institucional deriva de Unipar `#c8102e` (`oklch(0.523 0.214 26)`).
- Navegação por âncoras em página única (`/#secao`); header fixo vermelho que encolhe ao rolar.
- O **mapa das unidades** é um SVG inline gerado por `js/map.js` com dados **pré-computados** a partir de `data/parana.geojson` (Web Mercator, norte em cima, viewBox 800×600) — sem fetch, então funciona abrindo `index.html` por `file://`; substitui o `react-simple-maps` do original.
- Formulário de contato validado em `js/contact.js` e enviado por `fetch` à Function serverless `api/contact.js`, que integra com **Resend** (chave só no servidor). Para testes locais use `.env` + `vercel dev`.
- A **entrance screen** aparece 1x por sessão via `sessionStorage`.
- A logo é carregada de URL externa (Vercel Blob) com `mix-blend-mode: screen`; existe cópia local em `img/`.
- A logo do header (imagem 1920×1080 com símbolo+texto centralizados) precisa de caixa com aspecto ≈ **3.7** (ex.: 178×48, 148×40) sob `object-fit: cover` para não cortar o topo do símbolo; caixas 16:9 classicistas (ex.: 224×48) cortam o símbolo.
- Imagens: fotografias usam `object-cover`; pôsteres/artes usam `object-contain` (regra obrigatória). **Exceção (2026-09-14):** fotos panorâmicas muito largas que perderiam conteúdo sob `cover` (ex.: `sescoop-4`, `sescoop-5`) são exibidas inteiras via classe escopada (`.case-image-duo--sescoop`) com `aspect-ratio: auto` + `height: auto` + `object-fit: contain`.
